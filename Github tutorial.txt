##Git basic command

1> Creating a Repository (git init)

->It is used to create and initilize a new git repository in folder.

->It create a hidden .git folder in our directory. where git store all tracking information.

->Syntax : git init

2> Checking Status (git status)

-> It is used to check current status of our git repository

-> what does git status do ?
  It show which files are stagged, unstagged or tracked.
  it helps to see if there are changes to commit, files to stage or untracked files.

->Syntax : git status

3> Adding repository

-> It is used to add chnages from the working directory to the staging area.
-> It mark the file for inculsion in the next commit.

->Syntax : git add (filename) 
		   git add * 
		   git add .
		   
4> Commit changes 

-> It is used to save  the changes from the stagging to git repository.
-> Sysntax : git commit -m "first commit"

5> verifying command

-> It is used to view the commit history of a git repository

-> It delays a list of commits in reverse order, showing the most recent commits first.

-> Syantax : git log 
             git log --oneline

6> difference command

-> It is used to show the difference between the working directory  and the staging area.

-> It is usefull for code review and debugging by checking the differnces before commiting chnages.

-> syntax : git diff
            git diff commit 1 commit 2

7> clone command

-> It is used to create a copy of an existing Git repository from a remote server (like GitHub, GitLab) to our local machine.

-> It will download all files, commit history, branches and tags from the remote repository.

-> Syntax : git clone <repository-URL>
